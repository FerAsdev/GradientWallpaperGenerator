# Gradient Wallpaper Studio

App client-side para crear wallpapers de gradientes en ultra alta calidad. Incluye gradientes lineales, radiales, cónicos y un modo mesh moderno para fondos suaves y complejos.

## Características

- Detecta la resolución de pantalla y precarga tamaños recomendados.
- Exporta wallpapers PNG con escala de exportación.
- Paletas curadas y edición de stops con ordenamiento rápido.
- Previsualización en tiempo real y copia rápida del CSS.

## Uso

1. Abre `index.html` en tu navegador.
2. Ajusta el tipo de gradiente, stops y resolución.
3. Haz clic en **Renderizar canvas** y luego en **Exportar PNG**.

## Sugerencias

- Para lograr más nitidez, aumenta la escala de exportación a 1.5x o 2x.
- Usa el modo mesh para gradientes modernos tipo “blobs”.
